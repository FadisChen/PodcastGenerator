# Podcast 生成器 Chrome 擴充功能

## 功能特色

### 🎯 主要功能
1. **側邊欄介面** - 點擊擴充功能圖示開啟側邊欄
2. **API 金鑰管理** - 安全儲存 Gemini API 金鑰
3. **素材輸入** - 多種方式輸入講稿素材
4. **網頁元素擷取** - 類似 F12 開發者工具的元素選取功能
5. **智能搜尋** - Google 搜尋和 Tavily 深度搜尋
6. **語音設定** - 支援單人和雙人語音模式
7. **講稿生成** - AI 自動生成專業講稿
8. **講稿強化** - 針對深度、精簡、語調等面向重寫講稿
9. **音檔生成** - 高品質語音合成
10. **音檔管理** - 播放和下載功能

### 🛠️ 素材來源
- **網頁擷取**: 直接從網頁選取元素文字
- **Google 搜尋**: 使用 Gemini 的 Google Search Grounding
- **Tavily 搜尋**: 支援深度搜尋和內容提取

### 🎤 語音設定
- **單人演講**: 選擇一個語音角色和講者名稱
- **雙人對話**: 選擇兩個不同語音角色和講者名稱

### 🎨 風格設定
- 可自定義講稿風格（預設為 Podcast 風格）
- 支援多種用途：教育、商業、娛樂等

### 🔊 音檔功能
- 自動分段處理長講稿
- 智能合併音檔片段
- WAV 格式輸出
- 支援下載功能

## 安裝方式

1. 下載整個 Extension 資料夾
2. 開啟 Chrome 瀏覽器
3. 進入 `chrome://extensions/`
4. 開啟「開發者模式」
5. 點擊「載入未封裝項目」
6. 選擇 Extension 資料夾

## 使用說明

### 第一次使用
1. 點擊擴充功能圖示開啟側邊欄
2. 輸入您的 Gemini API 金鑰並儲存
3. 開始使用各項功能

### 網頁元素擷取
1. 點擊「網頁擷取」按鈕
2. 在網頁上移動滑鼠，元素會被高亮顯示
3. 點擊要擷取的元素
4. 文字內容將自動填入素材輸入框
5. 點擊右上角的「✕ 取消擷取」按鈕可取消選取

### 生成講稿
1. 在素材輸入框中輸入或擷取內容
2. 選擇語音設定（單人或雙人）
3. 輸入風格要求
4. 點擊「生成講稿」按鈕

### 生成音檔
1. 確保已有講稿內容
2. 點擊「生成音檔」按鈕
3. 系統會自動處理長講稿的分段
4. 完成後可播放和下載音檔

## 技術特點

- **Manifest V3** - 使用最新的 Chrome 擴充功能標準
- **Side Panel API** - 現代化的側邊欄介面
- **Chrome Storage API** - 安全的本地儲存
- **Content Scripts** - 網頁內容互動
- **自定義 CSS** - 清新且符合主題的 UI 設計
- **預設模型** - 文字生成預設使用 `gemini-3.5-flash-lite`，語音合成預設使用 `gemini-3.1-flash-tts-preview`，皆可於設定視窗中自訂

## 注意事項

1. 需要有效的 Gemini API 金鑰
2. 網路連線穩定以確保 AI 功能正常
3. 長講稿會自動分段處理，請耐心等待
4. 建議在使用前先測試較短的內容

## 常見問題

**Q: 為什麼無法選取網頁元素？**  
A: 請確保已給予擴充功能必要的權限，並重新整理網頁後再試。

**Q: API 金鑰儲存安全嗎？**  
A: 金鑰儲存在本地瀏覽器中，不會上傳到任何伺服器。

**Q: 音檔生成失敗怎麼辦？**  
A: 請檢查網路連線和 API 金鑰，如果講稿太長會自動分段處理。

**Q: 講稿改寫/強化功能出現 API 錯誤怎麼辦？**  
A: 若持續出現錯誤，請確認設定中的文字生成模型名稱正確（預設 `gemini-3.5-flash-lite`）。Gemini 3 系列模型已改用 `thinkingLevel` 取代舊版 `thinkingBudget` 參數，若自訂了其他 3.x 系列模型，混用兩者會導致 API 回傳錯誤或空白回應。
